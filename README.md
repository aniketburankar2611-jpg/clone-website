# Clone Website

This repository was created as a **learning project while I was learning Git and GitHub**. The main purpose of this project is to practice working with repositories, commits, branches, file management, and other basic GitHub concepts.

## 📌 About the Project

This project is a simple **website clone** created for educational and practice purposes. While building it, I focused on understanding how a website can be structured and how a project can be managed using Git and GitHub.

The project is not intended to be a production-ready website. Instead, it represents my learning journey and my first steps toward becoming more comfortable with version control and web development.

## 🎯 Purpose of This Repository

I created this repository to practice:

* Creating a GitHub repository
* Cloning a repository to my local computer
* Adding and modifying files
* Tracking changes with Git
* Creating commits
* Writing meaningful commit messages
* Pushing changes to GitHub
* Understanding the basic Git workflow
* Organizing files in a web development project
* Learning how GitHub can be used to store and manage projects


By working on this project, I am getting more familiar with the process of making changes locally, saving those changes through commits, and synchronizing the project with a GitHub repository.
